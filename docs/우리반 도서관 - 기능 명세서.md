# 우리반 도서관 - 기능 명세서

Sep 29, 2026 · @바바바

## 문서 목적 및 범위

이 문서는 우리반 도서관 앱의 1차(MVP) 개발 범위에 해당하는 모든 화면과 기능의 상세 동작을 정의합니다. 개발자가 이 문서만으로 화면 구성, 데이터 흐름, 처리 로직을 구현할 수 있도록 작성되었습니다. 콘텐츠 관리 기준, 보안 수준 등 정책적 판단이 필요한 사항은 별도 정책서를 따릅니다.

## 코드 체계

모든 출입구는 도서관 문의 하나의 코드 입력창으로 통합된다. 서버는 입력값의 형식으로 두 종류를 자동 구분한다.

| 코드 | 형식 | 발급 시점 | 입력 시 동작 |
| --- | --- | --- | --- |
| 학급 코드 | 숫자 6자리 고정 | 학급 생성 시 1회 발급, 학기/학년 동안 고정 | 안내소로 이동(아이용 플로우) |
| 작가 코드 | 영문+숫자 조합 | 작가실을 처음 만들 때 자동 발급 | 해당 작가가 발행한 책 목록(읽기 전용)으로 즉시 이동 |

작가 코드는 재발급 가능하며, 재발급 시 기존 코드는 즉시 무효화됩니다. 정원(3층 미니 정원)은 별도 코드 없이 이름으로만 구분되는 독립 식별자입니다.

## 화면별 상세 기능 명세

| 화면 | 주요 구성 | 핵심 동작 |
| --- | --- | --- |
| 초기화면 | "우리반 도서관" 타이틀, 중앙에 큰 도서관 일러스트, 자연친화적이고 아기자기한 배경 | 도서관 문 터치 시 유도 모션 후 코드 입력창 표시. 이 입력창은 학급 코드와 작가 코드를 함께 받는다: 학급 코드면 안내소로 이동(아이용), 특정 작가의 작가 코드면 바로 그 작가의 책 목록(읽기 전용)으로 이동(학부모용) |
| 안내소 | 도서관 프론트 데스크 느낌의 디자인, 1층/2층/3층 안내판 | 1층 터치 → 서고, 2층 터치 → 작가실 로비, 3층 터치 → 옥상 |
| 1층 서고 | 도서관 내부 인테리어, 작가(아이) 목록 | 작가 선택 → 그 작가의 책 목록으로 이동. 안내소로 돌아가기 버튼 상시 |
| 작가의 책 목록 | 선택한 작가가 발행한 책 표지 모음 | 책 선택 → 전자책 리더로 이동 |
| 전자책 리더 | 실제 책처럼 페이지 넘김 애니메이션 | 페이지를 넘길 때마다 해당 페이지에 녹음된 음성이 자동 재생 |
| 2층 작가실 로비 | 개인 작가실 목록(이름/아이콘으로 표시), 작가실 생성 버튼 | 로그인 없이 목록에서 자기 작가실 터치 → 바로 해당 작가실로 이동. 생성 버튼 → 이름 입력으로 새 작가실 만들기 — 이때 자동으로 고유 작가 코드도 함께 발급됨. 안내소로 돌아가기 버튼 상시 |
| 개인 작가실 | 좌상단 작가 프로필(SNS 프로필 느낌)에 학부모 공유용 작가 코드 표시(복사 버튼 포함), 좌하단 "새로운 책 쓰기" 버튼, 우측에 "내가 만든 책" 목록 | 새 책 쓰기 → 책 만들기 플로우 시작. 기존 책은 자유롭게 선택해 수정/삭제 가능 |
| 책 만들기 - 사진 등록 | 사진 넣기 버튼, 등록 순서대로 번호 매겨진 사진 그리드 | 사진을 드래그해 순서 수정, 완료 후 "책 만들기" 버튼 |
| 책 만들기 - 조립 | 사진들이 책 페이지로 조립되는 애니메이션(책장 넘기는 모션) | 자동 진행 후 녹음 단계로 |
| 책 만들기 - 녹음 | 페이지 한 장씩 넘어가며 녹음 | 페이지별 녹음/재녹음, 완료 후 "발행" 버튼 |
| 발행 완료 | 발행 버튼 터치 시 승인 절차 없이 즉시 처리 | 발행 즉시 1층 서고에 공개 + 개인 작가실 "내가 만든 책"에 추가. 해당 작가의 작가 코드로 도서관 문에서 바로 열람 가능해짐. 이후에도 자유롭게 재수정/삭제 가능 |
| 3층 옥상 | 아이들 개인별 미니 정원 목록(이름/아이콘)과 "새 정원 만들기" 버튼 | 정원 선택 → 바로 그 정원으로 이동(로그인·PIN 없음). 새 정원 만들기는 이름과 아이콘(꾸미기 요소) 선택으로 생성. 안내소로 돌아가기 버튼 상시 |
| 개인 미니 정원 | 화면 중앙에 알 또는 부화한 벌레/동물, 하단에 먹이 추가·먹이 주기·도감 버튼, 우측 상단에 옥상으로 가기 버튼 | 알 상태에서 알을 터치하면 부화 애니메이션 후 벌레/동물 등장. 먹이 추가 → 독서 등록창으로 이동. 먹이 주기 → 먹는 모션 재생, 10회 먹으면 성장해 도감에 카드로 등록되고 새 알이 다시 생성됨. 도감 → 도감 화면으로 이동 |
| 독서 등록창 | 책 제목 입력창, 녹음 방식/직접쓰기 방식 선택, 지금까지 등록한 독서 기록 누적 목록 | 책 제목을 자유롭게 입력하고 녹음 또는 글쓰기로 독서를 등록하면 먹이가 1개 생성됨. "정원가기" 버튼으로 정원(벌레/동물 화면)으로 복귀 |
| 도감 | 지금까지 모은 다양한 동물 카드 컬렉션(그리드 형태) | 카드를 터치하면 동물 사진과 간단한 특징 설명이 표시됨. 정원으로 돌아가기 버튼 상시 |

## 3층 옥상 - 독서 육성 시스템 상세 로직

2층 작가실과는 별개의 개인 공간으로, 아이 개인별 독서 습관을 게임처럼 만드는 수집형 육성 시스템입니다.

1. **옥상 진입**: 안내소에서 3층 선택 → 옥상 화면에 개인별 미니 정원 목록과 "새 정원 만들기" 버튼이 표시된다. 로그인이나 PIN 없이 목록에서 선택하면 바로 입장하며, 새 정원은 이름과 아이콘 선택으로 생성된다. 작가실과는 완전히 별개의 식별자로 관리된다
2. **부화**: 알 상태에서 알을 터치하면 부화 애니메이션 후 벌레/동물이 등장한다
3. **독서 등록(먹이 추가)**: 책 제목을 자유롭게 입력하고(앱 안의 책은 물론 집에서 읽은 책 등 어떤 책이든 등록 가능), 녹음 또는 직접 글쓰기 중 하나로 등록한다. 등록할 때마다 지금까지의 독서 기록이 누적 목록으로 함께 표시된다. 등록 완료 시 먹이 1개가 생성되며, 등록 횟수에는 하루/기간 제한이 없다. "정원가기" 버튼으로 정원 화면으로 돌아간다
4. **먹이 주기**: 버튼을 누르면 먹는 모션이 재생되고 먹이 1개가 소모된다(먹이가 없으면 먹일 수 없음). 누적 10회 먹이면 성장하여 동물 카드가 되어 도감에 자동 등록되고, 화면에는 새로운 알이 다시 나타나 사이클이 반복된다
5. **도감**: 지금까지 모은 동물 카드 컬렉션이 그리드로 표시되며, 특정 종·개수로 제한되지 않는다. 카드 터치 시 동물 사진과 간단한 특징 설명이 표시된다

## 선생님 관리자모드 기능명세

- **로그인**: 학급 생성 시 설정한 이메일+비밀번호로 로그인(비밀번호 찾기 포함). 초기화면의 "선생님이신가요?" 링크로 진입
- **개요 화면**: 도서관 이름, 학급 코드(재확인/복사), 작가실 수, 발행된 책 수
- **발행된 책 관리**: 전체 책 목록(작가·발행일·페이지 수). 클릭 시 사진+녹음 미리보기 가능. 각 항목에 "숨기기"(즉시 비공개, 바로 복구 가능)와 "삭제"(휴지통으로 이동) 버튼
- **휴지통**: 삭제된 책은 30일간 보관되며 그 사이 "복구" 가능. 기간 만료 시 자동으로 영구 삭제
- **작가실 관리**: 학생(작가실) 목록, 이름 오타 수정, 작가 코드 확인/재발급(재발급 시 기존 코드 즉시 무효화), 작가실 삭제(비활성화 — 이미 발행된 책은 서고에 유지되나 해당 작가 코드로는 더 이상 읽을 수 없음)
- **정원/독서기록 관리**: 학생별 미니 정원 목록, 부적절한 독서 기록(녹음/글) 숨기기·삭제, 정원 삭제(비활성화)
- **학급 코드 확인 화면**
- **권한 범위**: 사진·녹음 콘텐츠 자체는 수정하지 않고, 숨김/삭제/복구/작가실·정원 관리 등 운영 기능만 수행

## 데이터 모델

| 엔티티 | 주요 속성 |
| --- | --- |
| 학급(도서관) | 학급 코드, 이름, 개설일, 선생님 이메일/비밀번호 |
| 작가실 | 이름, 작가 코드, 상태(활성/비활성화) |
| 책 | 제목, 작가, 페이지 수, 발행상태(발행됨/숨김됨/휴지통/영구삭제), 발행일 |
| 페이지 | 사진 파일, 녹음 파일, 순서 |
| 미니 정원 | 이름, 꾸미기 요소(아이콘), 캐릭터 상태(알/부화/성장), 먹이 개수, 누적 먹인 횟수 |
| 독서기록 | 책 제목(자유 입력), 녹음 파일 또는 텍스트, 등록일시, 소속 정원 |
| 도감카드 | 동물 종류, 사진, 특징 설명, 소속 정원, 등록일 |

이 외에 책과 독서기록은 각각 상태값을 갖고 있으며, 상태 변화 이력(숨김/삭제/복구 시점)은 관리자 모드의 운영 기록으로 남기는 것을 권장한다.

## 기술 요구사항

- **프론트**: 반응형 웹앱(태블릿/모바일 브라우저 기준). 아이용 화면과 선생님용 관리자 화면은 라우트로 분리(예: /admin). 학부모용 화면은 별도 라우트 없이 도서관 문 코드 입력 결과에 따라 분기되는 화면 상태로 구현
- **백엔드**: 고정 코드 인증(아이용) + 작가 코드 읽기 전용 접근(학부모용) + 이메일/비밀번호 인증(선생님용), 이미지/오디오 파일 업로드와 클라우드 저장, 데이터베이스
- **도서관 문 코드 입력 처리**: 입력값을 학급 코드 테이블과 작가 코드 테이블에 각각 조회해 일치하는 쪽으로 분기
- **책 상태값 관리**: 발행됨/숨김됨/휴지통(30일 후 자동 영구삭제)/영구삭제된 상태를 관리하는 백엔드 로직(휴지통 자동 만료 처리는 스케줄러/배치 작업)
- **카메라/녹음**: 사진 촬영 후 즉시 업로드(오프라인 촬영 미지원), 녹음/재생 기능(시간 제한 없음). 페이지 넘김 시 해당 페이지 오디오 자동 재생
- **육성 로직(3층 옥상)**: 독서 등록 1건당 먹이 1개 지급 → 먹이 주기 10회 누적 시 캐릭터 성장 → 도감 카드 저장 + 새 알 자동 생성(먹이 개수와 먹인 횟수를 정원별로 추적)
- **발행 로직**: 승인 없이 즉시 처리(발행 시 별도 공유 링크는 생성하지 않음 — 작가 코드가 그 역할을 대체)
